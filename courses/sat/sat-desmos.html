Desmos tactics

Solve equations and systems by graphing, regressions from tables, sliders, statistics and more, with Desmos built right into the page.

★Why Desmos is your biggest advantage

The Desmos graphing calculator is built into every SAT Math question. Used well, it turns many algebra problems into "type it in and click." Open it with the ƒ Desmos button (bottom right) and try every tactic on this page as you read. Click any gray code chip to copy it, then paste it into Desmos.

Typing shortcuts

sqrt → √, pi → π, ^ for exponents, / makes a fraction, |x| or abs(x) for absolute value, <= → ≤.

Practice the real one

Bluebook's calculator is Desmos with a few features turned off. Practice in the test version too: desmos.com/testing → "Digital SAT."
Know when NOT to use itIf you can do it in your head in 10 seconds (3x = 12), just do it. Desmos is for anything with a graph, a quadratic, a system, a table of data, or a messy equation.

1Solving equations and systems

1Solve any equation in one variable

Any equation you'd have to rearrange or factor. Type the whole equation; Desmos draws vertical lines (or gray points) at the solutions.

Type:2x^2-3x-9=0 sqrt(x+3)=x-3

Click the gray dots on the x-axis to read each solution. With a radical, Desmos automatically ignores the extraneous solution.

2Solve a system

Two equations, any form. Type both; click where they cross.

Type:2x+3y=12 x-y=1

Read the intersection: (3, 2). No elimination needed. Nonlinear systems work the same way: count the crossings to answer "how many solutions."

3Graph both sides

When an equation has x on both sides or looks ugly, graph y = left side and y = right side separately. The x-values where they cross are the solutions.

Type:y=2^x y=x+3

2Regressions: the tactic most students don't know

Whenever a question gives you a table of values or a few points and asks for an equation, a constant, or a prediction, let Desmos find the equation with a regression. Type a table (click + → table), then a regression with a tilde ~:

ModelType in DesmosUse when
Lineary_1 ~ mx_1+bconstant differences
Quadraticy_1 ~ ax_1^2+bx_1+cparabola, "quadratic function f"
Exponentialy_1 ~ ab^{x_1}constant ratios, growth/decay
Worked example: A quadratic function f has f(1) = 2, f(2) = 7, f(3) = 14. What is f(5)?
Table: x₁ = 1, 2, 3 and y₁ = 2, 7, 14. Type y_1 ~ ax_1^2+bx_1+c → a = 1, b = 2, c = −1, r² = 1. Then type 5^2+2*5-1 → 34. (Or define f(x) = x² + 2x − 1 and type f(5).)
Worked example: x: 0, 1, 2, 3; y: 5, 15, 45, 135. Which equation models this?
y_1 ~ ab^{x_1} gives a = 5, b = 3: y = 5(3)ˣ.
r² = 1 means exactIf r² = 1, the equation passes through every point: it's THE equation, not an estimate. If r² is less than 1, it's a line/curve of best fit (good for scatterplot questions).

3More tactics

4Sliders for unknown constants

"For what value of k…" questions. Type the equation with a letter; Desmos offers a slider. Drag until the condition happens (one solution, lines parallel, curve through a point).

Type:y=x^2-6x+k y=0

Drag k until the parabola just touches y = 0: k = 9. Confirm with algebra (b² − 4ac = 0) if the slider lands between values.

5Function notation

Define the function once, then evaluate or compose by typing.

Type:f(x)=3x^2-2 f(4) g(x)=x+1 f(g(2))

6Vertex, zeros and max/min

Click the curve: Desmos shows gray points at x-intercepts, y-intercept, and the max/min.

Type:y=-2x^2+12x-7

Vertex (3, 11): the maximum value is 11 at x = 3.

7Statistics

Mean, median and standard deviation of a list.

Type:mean([12,15,15,18,40]) median([12,15,15,18,40]) stdev([2,4,4,4,5,5,7,9])

Use this to compare spreads of two data sets quickly.

8Equivalent expressions

Graph the original and each answer choice. The one that lies exactly on top is equivalent.

Type:y=(2x-3)^2-4x y=4x^2-16x+9

9Inequalities and points

Type the inequality to shade the solution region; type the point to see if it's inside.

Type:y>2x-1 y<-x+5 (1,2)

10Circles

Type the circle in any form. Hover or click the top/bottom/left/right points to read the center and radius.

Type:x^2+6x+y^2-4y=12

Leftmost (−8, 2), rightmost (2, 2): center (−3, 2), radius 5.

11Restrict a domain

Graph only part of a function with curly braces.

Type:y=x^2\{x>0\}

12Trig in degrees

SAT Desmos starts in radians. Click the wrench (settings) → Degrees before any trig question with degrees.

Type:sin(30)

If sin(30) shows −0.988, you're in radians.
