★How to use this practice test

This is a full-length SAT: four modules, 98 questions, written in the style of the real test. Module 2 of each section is the harder version, the one you'll see if Module 1 goes well.

  1. Set aside about 2 hours 20 minutes. Take a 10-minute break between Reading and Writing and Math.
  2. Do the modules in order. Don't look things up.
  3. Afterward, review every question you missed or guessed on. Each review shows a skill breakdown so you know which lesson page to revisit.
  4. Then take an official full-length test in the Bluebook app for a real scaled score.
Why no score conversion?The real SAT scales scores using question difficulty data we don't have, so any 400–1600 number here would be a guess. Use the percent correct and skill breakdown instead.
