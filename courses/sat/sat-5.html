5.1Quadratics

Three forms, three jobs. Know which feature each one shows instantly.

FormShows
y = a(x − h)² + kvertex (h, k): the max or min
y = a(x − r)(x − s)x-intercepts r and s; vertex x is halfway: (r + s)/2
y = ax² + bx + cy-intercept c; vertex x = −b/(2a); sum of roots −b/a; product c/a

Discriminant

b² − 4ac > 0: two real solutions; = 0: one; < 0: none. Questions like "for what c does the equation have exactly one solution" are discriminant questions.

Desmos move

Graph the quadratic and click the vertex and zeros. Graph y = (your expression) and y = (other side) to solve any equation.
Worked example: x² − 6x + c = 0 has exactly one real solution. Find c.
b² − 4ac = 36 − 4c = 0 → c = 9.

5.2Exponential functions

f(x) = a·bˣ: a is the starting value; b is the growth factor. Growth by r%: b = 1 + r/100. Decay by r%: b = 1 − r/100.

StatementModel
increases 8% per yearP(t) = P₀(1.08)ᵗ
decreases 30% per yearV(t) = V₀(0.7)ᵗ
doubles every 6 hoursN(t) = N₀·2^(t/6)
halves every 3 daysA(t) = A₀(½)^(t/3)
Linear vs exponential"Increases by 5 each year" is linear (add). "Increases by 5% each year" is exponential (multiply).

5.3Equivalent expressions and polynomials

Fast check

Plug x = 2 into the original and each choice. Equivalent expressions give the same number.

Factor patterns

a² − b² = (a − b)(a + b); a² ± 2ab + b² = (a ± b)².

Rational expressions & radicals: x^(1/2) = √x, x^(m/n) = (ⁿ√x)^m, x^(−n) = 1/xⁿ. To solve √(x + 3) = x − 3, square both sides, then check for extraneous solutions.

5.4Function notation, transformations and nonlinear systems

f(x + 2) shifts the graph left 2; f(x) + 2 shifts it up 2. For f(g(x)), work from the inside out.

Setting x² − 2 = mx + b gives x² − mx − (b + 2) = 0. Positive discriminant → 2 crossing points, zero → tangent (1), negative → none.
