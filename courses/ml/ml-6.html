Clusters, embeddings and transformers

k-means, PCA, embeddings, attention, large language models and how to use machine learning responsibly.

6.1Clustering with k-means

With no labels, we can still look for structure. Clustering groups examples so that points in the same group are similar. k-means is the classic algorithm:

  1. Pick k starting centers (centroids), for example k random data points.
  2. Assign every point to its nearest center.
  3. Update each center to the mean of the points assigned to it.
  4. Repeat steps 2–3 until no point changes cluster.

What it minimizes

The inertia: the total squared distance from each point to its center. Each step can only lower it, so k-means always stops, but possibly in a poor local minimum. Run it several times from different starts and keep the best (k-means++ picks smart starting centers).

Choosing k

Inertia always drops as k grows (k = n gives 0). Plot inertia against k and look for the 'elbow' where adding clusters stops helping much.

Limitations

Assumes round, similar-sized clusters. Fails on moons and rings, where density-based methods like DBSCAN work better. Scale features first: it uses distances.

Uses

Customer segments, grouping news articles, compressing an image to k colors, and as a first look at any new dataset.
Worked example: Points 1, 2, 3, 10, 11, 12 on a line, k = 2, starting centers 1 and 2. Run k-means.
Assign: 1 → center 1; 2, 3, 10, 11, 12 → center 2. Update: centers 1 and (2+3+10+11+12)/5 = 7.6. Assign: 1, 2, 3 → center 1 (3 is 2 from 1, 4.6 from 7.6); 10, 11, 12 → 7.6. Update: 2 and 11. Assign: nothing changes. Done: {1, 2, 3} and {10, 11, 12}.

6.2Dimensionality reduction: PCA

Real data often has hundreds of features, many of them redundant (height in cm and height in inches). Principal component analysis finds new axes, called principal components, along which the data varies the most, and keeps only the top few.

PC1

The direction of greatest variance. PC2 is the direction of greatest remaining variance at right angles to PC1, and so on.

Explained variance

Each component reports the share of the total variance it captures. Keep enough components to explain, say, 95%.

Uses

Plotting high-dimensional data in 2D, speeding up other models, removing noise, compressing data.

Under the hood

The components are the eigenvectors of the data's covariance matrix, ranked by their eigenvalues (the variance along each).
Standardize firstPCA chases variance, so a feature measured in large units (salary in dollars) would dominate one in small units (age). Standardize features before running PCA.

6.3Embeddings: meaning as vectors

An embedding represents a word, image, song or user as a list of numbers (a vector, often 256–4096 long) learned so that similar things end up close together. Word embeddings famously capture relationships as directions:

vec(king) − vec(man) + vec(woman) ≈ vec(queen)

Closeness is usually measured with cosine similarity, the cosine of the angle between two vectors:

cos θ = (a · b) / (‖a‖ ‖b‖)

1 means pointing the same way, 0 means unrelated (perpendicular), −1 means opposite. Search engines, recommendation systems and "find similar photos" all work by embedding things and finding nearest neighbours.

Worked example: Cosine similarity of a = (1, 2, 2) and b = (2, 0, 1)?
a · b = 2 + 0 + 2 = 4. ‖a‖ = 3, ‖b‖ = √5 ≈ 2.236. cos θ = 4 / 6.71 ≈ 0.60.

6.4Transformers and attention

The transformer (2017, "Attention Is All You Need") is the architecture behind modern language, image and audio models. Its key part is self-attention: every token looks at every other token and decides how much to borrow from each.

  1. Each token's embedding is turned into three vectors: a query q (what am I looking for?), a key k (what do I contain?) and a value v (what do I pass along?).
  2. The relevance of token j to token i is the dot product qᵢ · kⱼ, scaled by √d (d = vector length).
  3. Softmax turns those scores into weights that add up to 1.
  4. Token i's new representation is the weighted sum of all the values.
Attention(Q, K, V) = softmax(QKᵀ / √d) · V

Multi-head attention

Several attention operations run in parallel, each free to track a different relationship (who did what, what modifies what, which words rhyme).

Position

Attention by itself ignores word order, so position information is added to each token's embedding.

Why it won

Every token is processed in parallel (unlike RNNs, which go one step at a time), so transformers train efficiently on GPUs and scale to enormous datasets.

Beyond text

Vision transformers split images into patches and treat them as tokens; the same idea works for audio, protein sequences and more.

6.5Large language models

A large language model is a transformer trained to predict the next token (a word or piece of a word, like "un" + "believ" + "able") given all the tokens before it. Trained on a huge amount of text, getting good at that one task forces it to pick up grammar, facts, reasoning patterns and style.

StageWhat happens
PretrainingSelf-supervised next-token prediction on a vast text corpus. The most expensive stage.
Fine-tuningFurther training on curated examples of following instructions and holding conversations.
Preference training (e.g. RLHF)People (or models) compare responses; the model is trained toward the preferred ones, for helpfulness and safety.
GenerationRepeatedly predict a probability distribution over the next token, sample one, append it, repeat.

Temperature

Logits are divided by a temperature T before softmax (the softmax lab in unit 3 has this slider). Low T: nearly always the most likely token, focused and repetitive. High T: more varied and creative, more likely to wander.

Context window

The maximum number of tokens the model can attend to at once. Anything outside it is invisible to the model.

Hallucination

A model trained to produce plausible text can produce plausible-sounding but false statements. Check important facts against sources.

Scaling

Performance has improved smoothly and predictably with more parameters, more data and more compute, which is why models have grown so large.
Worked example: A model's logits for the next token are (3, 1, 0) for 'cat', 'dog', 'car'. Probabilities at T = 1 and at T = 0.5?
T = 1: e³ ≈ 20.1, e¹ ≈ 2.72, 1 → (0.84, 0.11, 0.04). T = 0.5: logits become (6, 2, 0): e⁶ ≈ 403, e² ≈ 7.39, 1 → (0.98, 0.02, 0.002). Lower temperature makes 'cat' almost certain.

6.6Responsible machine learning

Bias in, bias out

A model learns whatever patterns are in its data, including unfair ones. A hiring model trained on past decisions can copy past discrimination. Facial recognition trained mostly on some groups works worse on others.

Measuring fairness

Compare error rates across groups: false positive and false negative rates, precision and recall per group. Different fairness definitions can conflict, so the choice is a judgement about values, not just math.

Privacy

Models can memorize and leak training data. Techniques include removing personal data, aggregating, and differential privacy (adding carefully calibrated noise).

Distribution shift

The world changes: a model trained before an event may fail after it. Monitor live performance and retrain.

Explainability

In high-stakes decisions (loans, medicine, justice) people deserve reasons. Simple models, feature importance, and tools like SHAP help explain predictions.

Human oversight

Keep a human in the loop for consequential decisions, and design for what happens when the model is wrong.
