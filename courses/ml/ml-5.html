Neural networks

Neurons, activations, layers, backpropagation and convolutional networks, with a playground where you can watch a network learn.

5.1The artificial neuron

An artificial neuron is logistic regression wearing a different hat: it multiplies each input by a weight, adds them up with a bias, and passes the total through an activation function.

a = f(w₁x₁ + w₂x₂ + … + b) = f(w · x + b)
ActivationFormulaRangeNotes
Sigmoid1/(1 + e⁻ᶻ)(0, 1)good for a probability output; slow to train in hidden layers
tanh(eᶻ − e⁻ᶻ)/(eᶻ + e⁻ᶻ)(−1, 1)centred at 0
ReLUmax(0, z)[0, ∞)the default for hidden layers: cheap, and gradients don't fade for z > 0
Step1 if z ≥ 0 else 0{0, 1}the original 1958 perceptron; can't be trained by gradient descent
Why we need nonlinear activationsStack two linear layers and you get W₂(W₁x) = (W₂W₁)x: still just one linear layer. Without a nonlinear activation between layers, a 100-layer network is no more powerful than logistic regression.

5.2Layers and the forward pass

A neural network (multilayer perceptron) arranges neurons in layers. Every neuron in one layer feeds every neuron in the next (fully connected or dense). The layers between input and output are hidden layers; "deep" learning just means many of them.

h = f(W₁x + b₁)      ŷ = g(W₂h + b₂)

Each layer is a matrix multiply, plus a bias vector, then an activation. A layer with 3 inputs and 4 outputs has a 4 × 3 weight matrix (12 weights) and 4 biases: 16 parameters.

The universal approximation theorem says a network with one hidden layer and enough neurons can approximate any continuous function as closely as you like. In practice, deeper networks learn the same functions with far fewer neurons, building complex features out of simpler ones layer by layer.

5.3Training: backpropagation

Training a network is gradient descent again: compute the loss, compute the gradient of the loss with respect to every weight, step downhill. The trick is computing millions of gradients efficiently. Backpropagation does it with the chain rule, working backwards from the loss, reusing each layer's result for the layer before.

∂L/∂w = ∂L/∂ŷ · ∂ŷ/∂z · ∂z/∂w

The training loop

  1. Take a mini-batch of examples.
  2. Forward pass: compute predictions and the loss.
  3. Backward pass: backpropagate to get every gradient.
  4. Update: the optimizer adjusts every weight.
  5. Repeat for many epochs, watching the validation loss.
import torch, torch.nn as nn
model = nn.Sequential(nn.Linear(2, 8), nn.ReLU(), nn.Linear(8, 1))
opt = torch.optim.Adam(model.parameters(), lr=0.01)
loss_fn = nn.BCEWithLogitsLoss()
for epoch in range(200):
    for xb, yb in loader:              # mini-batches
        loss = loss_fn(model(xb), yb)  # forward pass
        opt.zero_grad()
        loss.backward()                # backpropagation
        opt.step()                     # gradient descent update

Optimizers

Plain SGD, SGD with momentum (keeps rolling in a consistent direction), and Adam (adapts the step size for each weight) are the common choices. Adam is the usual default.

Vanishing gradients

Sigmoid's slope is at most 0.25, so multiplying many of them in a deep network shrinks gradients toward 0 and early layers stop learning. ReLU, careful weight initialization and residual connections fix this.

Initialization

Weights start as small random numbers. If they all started equal, every neuron in a layer would compute the same thing and get the same update forever.

Hardware

Training is mostly huge matrix multiplications, which GPUs and TPUs do thousands at a time in parallel.
Detailed explanationWhy backprop is efficient

Computing each weight's gradient separately would repeat the same work over and over. Backprop computes ∂L/∂(layer output) once per layer, then reuses it for all of that layer's weights and to pass the gradient further back. The backward pass costs about the same as roughly two forward passes, no matter how many weights there are.

5.4Convolutional networks for images

A 1000 × 1000 color photo has 3 million inputs. A dense layer with 1000 neurons would need 3 billion weights, and it would have to learn "cat ear" separately for every position in the image. Convolutional neural networks (CNNs) solve both problems with small filters that slide across the image, sharing the same weights everywhere.

Convolution layer

Learns many small filters (3 × 3, 5 × 5). Early layers learn edges and colors; deeper layers combine them into textures, parts (eyes, wheels) and whole objects.

Pooling

Max pooling keeps the largest value in each 2 × 2 patch, halving the width and height. It makes the network cheaper and less sensitive to small shifts.

Parameters

A 3 × 3 filter on a 3-channel image has 3 × 3 × 3 = 27 weights + 1 bias, whatever the image size.

Output size

An n × n image with an f × f filter (no padding, stride 1) gives an (n − f + 1) × (n − f + 1) feature map. Padding with zeros keeps the size the same.

For sequences (text, audio, time series) the classic choice was the recurrent neural network (RNN) and its LSTM variant, which read one step at a time while carrying a memory. Since 2017 transformers (unit 6) have largely replaced them.

Unit summary

Neuron

a = f(w·x + b). ReLU = max(0, z) for hidden layers; sigmoid/softmax at the output. Nonlinearity is essential.

Network

Layers of matrix multiply + bias + activation. Parameters per dense layer = in × out + out.

Training

Forward pass → loss → backprop (chain rule) → optimizer step. Mini-batches, epochs, Adam. Beware vanishing gradients.

CNNs

Small shared filters slide over images; pooling shrinks. Output size n − f + 1. Transformers now dominate sequences.
