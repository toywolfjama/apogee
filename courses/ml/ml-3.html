Machine Learning · Unit 3

Sorting into classes

Logistic regression, decision trees, softmax and how to judge a classifier: confusion matrices, precision, recall, F1 and ROC curves.

3.1Logistic regression

For a yes/no question we want a probability between 0 and 1, not any real number. Logistic regression takes the linear score z = w · x + b and squashes it with the sigmoid function:

σ(z) = 1 / (1 + e−z)      P(y = 1 | x) = σ(w · x + b)

Reading the output

σ(z) = 0.83 means the model thinks there's an 83% chance this example is positive. To make a decision, compare with a threshold (usually 0.5).

Decision boundary

σ(z) = 0.5 exactly when z = 0, so the boundary is the set where w · x + b = 0: a straight line in 2D, a flat plane in higher dimensions.

Log-odds

z itself is the log of the odds: z = ln(p / (1 − p)). Each unit of a feature changes the log-odds by its weight.

Key values

σ(0) = 0.5, σ(2) ≈ 0.88, σ(−2) ≈ 0.12, σ(4) ≈ 0.98.

The loss: cross-entropy

MSE works poorly with probabilities. Instead logistic regression minimizes binary cross-entropy (log loss):

L = −[ y · ln(p) + (1 − y) · ln(1 − p) ]

If the true label is 1 and the model says p = 0.9, the loss is −ln 0.9 ≈ 0.105. If it confidently says p = 0.01, the loss is −ln 0.01 ≈ 4.6. Confident wrong answers are punished hard. Training uses gradient descent, and the gradient has a beautifully simple form: ∂L/∂w = (p − y)·x.

Worked example: A spam model has w = (1.2, 0.8) for features (number of links, number of ALL-CAPS words) and b = −4. An email has 2 links and 1 all-caps word. Probability it's spam?
z = 1.2(2) + 0.8(1) − 4 = −0.8. p = 1/(1 + e^0.8) = 1/(1 + 2.23) ≈ 0.31. Below 0.5, so it's classified not spam.

3.2Decision trees

A decision tree is a flowchart of yes/no questions: Is income > $50k? → Is debt < $10k? → approve. Each internal node tests one feature against a threshold, and each leaf gives a prediction. Trees are easy to read and explain, need no feature scaling, and handle mixed feature types.

To grow a tree, at each node try every feature and every threshold, and pick the split that makes the two children purest. Two common impurity measures, for class proportions p₁, p₂, …:

Gini = 1 − Σ pₖ²      Entropy = − Σ pₖ log₂ pₖ

The information gain of a split is the parent's impurity minus the weighted average impurity of the children. Repeat recursively until the leaves are pure or a stopping rule kicks in.

Trees overfit easilyGrown all the way, a tree can give every training example its own leaf: 100% training accuracy, poor test accuracy. Limit the maximum depth or the minimum number of examples per leaf, or prune the tree afterwards. Unit 4 shows how forests of trees fix this.

3.3More than two classes

For K classes (digits 0–9, or cat / dog / bird) a model outputs K scores called logits, one per class, and the softmax function turns them into probabilities that add up to 1:

pₖ = ezₖ / Σⱼ ezⱼ

The loss is categorical cross-entropy: −ln(p of the correct class). Another approach is one-vs-rest: train K separate binary classifiers ("cat or not?", "dog or not?") and pick the most confident.

Worked example: Logits (2, 1, 0) for (cat, dog, bird). Softmax probabilities?
e² ≈ 7.39, e¹ ≈ 2.72, e⁰ = 1. Total ≈ 11.11. p = (0.665, 0.245, 0.090). If the photo really is a dog, the loss is −ln 0.245 ≈ 1.41.

3.4Evaluating a classifier

Accuracy alone hides what kind of mistakes a model makes. The confusion matrix counts all four outcomes:

Predicted positivePredicted negative
Actually positiveTrue positive (TP)False negative (FN) — a miss
Actually negativeFalse positive (FP) — a false alarmTrue negative (TN)
Precision = TP / (TP + FP)    Recall = TP / (TP + FN)    F1 = 2·P·R / (P + R)

Precision

Of everything flagged positive, how much really was? High precision = few false alarms. Matters for spam filters (don't lose real email).

Recall (sensitivity)

Of all the real positives, how many did we catch? High recall = few misses. Matters for cancer screening and fraud.

F1

The harmonic mean of precision and recall; it's high only if both are high.

Trade-off

Lower the threshold → more positives flagged → recall up, precision down. Raise it → the opposite.

The ROC curve plots the true positive rate (recall) against the false positive rate FP / (FP + TN) for every possible threshold. The AUC (area under it) is the probability that a random positive gets a higher score than a random negative: 1.0 is perfect, 0.5 is coin-flipping.

Worked example: A disease test on 1,000 people: 50 are sick. It flags 60 people, of whom 45 are sick. Find precision, recall and accuracy.
TP = 45, FP = 15, FN = 5, TN = 935. Precision = 45/60 = 0.75. Recall = 45/50 = 0.90. Accuracy = (45 + 935)/1000 = 0.98.

Unit summary

Logistic regression

p = σ(w·x + b), σ(z) = 1/(1 + e⁻ᶻ). Boundary w·x + b = 0. Loss = cross-entropy; gradient (p − y)x.

Trees

Split on the feature/threshold that most reduces impurity. Gini = 1 − Σp², entropy = −Σp log₂ p. Limit depth to avoid overfitting.

Many classes

Softmax: pₖ = e^zₖ / Σ e^zⱼ. Loss −ln p(correct).

Metrics

Precision = TP/(TP + FP), recall = TP/(TP + FN), F1 = harmonic mean. Threshold trades them off. ROC/AUC summarize all thresholds.
