Machine Learning · Unit 2

Learning a line

Models, loss functions, least squares and gradient descent: the core loop of machine learning, worked out on the simplest model there is.

2.1The linear model

Linear regression is the "hello world" of machine learning, and the ideas in it (a model with parameters, a loss function, and an optimizer that lowers the loss) are exactly the ideas behind giant neural networks.

ŷ = w·x + b

With one feature this is the equation of a line: w (the weight) is the slope and b (the bias) is the intercept. Learning means finding the w and b that make ŷ as close as possible to the true y across the training data.

With d features each one gets its own weight:

ŷ = w₁x₁ + w₂x₂ + … + w_dx_d + b = w · x + b

The dot product w · x multiplies matching entries and adds them up. Each weight says how much the prediction changes when that feature goes up by 1, holding the others fixed.

Worked example: A house-price model is ŷ = 0.15·(sq ft) + 12·(bedrooms) − 1.1·(age) + 40, in $k. Predict a 1,600 sq ft, 3-bedroom, 10-year-old house.
ŷ = 0.15(1600) + 12(3) − 1.1(10) + 40 = 240 + 36 − 11 + 40 = 305, so about $305k. Each extra square foot adds $150, all else equal.

2.2Measuring error: the loss function

For each example the residual is the error y − ŷ. We need one number that summarizes how wrong the model is over the whole training set. The standard choice for regression is the mean squared error:

MSE = (1/n) Σ (ŷᵢ − yᵢ)²

Squaring makes every error positive and punishes big misses much more than small ones (an error of 4 costs 16, an error of 1 costs 1).

Worked example: Predictions 3, 5, 9 for true values 2, 5, 12. Find MSE, RMSE and MAE.
Errors 1, 0, −3. MSE = (1 + 0 + 9)/3 = 10/3 ≈ 3.33. RMSE ≈ 1.83. MAE = (1 + 0 + 3)/3 ≈ 1.33.

2.3The best line, in one step

For simple linear regression calculus gives the exact minimizer of the MSE, called ordinary least squares:

w = Σ(xᵢ − x̄)(yᵢ − ȳ) / Σ(xᵢ − x̄)²      b = ȳ − w·x̄

With many features the same idea becomes the matrix formula w = (XᵀX)⁻¹Xᵀy. It's exact, but inverting a matrix gets very expensive with lots of features, and most models (logistic regression, neural networks) have no closed-form answer at all. For those we need an algorithm that improves step by step.

2.4Gradient descent

Picture the loss as a landscape over every possible setting of the parameters. Gradient descent starts somewhere and repeatedly takes a small step downhill. The gradient (the vector of partial derivatives) points uphill, so we step against it:

w ← w − α · ∂L/∂w      b ← b − α · ∂L/∂b

α is the learning rate, the size of each step. For MSE on a line the derivatives are

∂L/∂w = (2/n) Σ (ŷᵢ − yᵢ)·xᵢ      ∂L/∂b = (2/n) Σ (ŷᵢ − yᵢ)

α too small

Tiny steps: it gets there, but takes forever.

α too large

Each step overshoots the bottom. The loss bounces around or blows up (diverges).

Local minima

On a bumpy loss, gradient descent can settle in a valley that isn't the lowest. Linear regression's MSE is a perfect bowl (convex), so there's only one minimum; neural networks aren't.

Stochastic GD

Computing the gradient over millions of examples is slow. Mini-batch SGD estimates it from a small random batch (say 32 examples) per step. Noisier, but far faster, and the noise even helps escape bad spots. One pass over the whole training set is an epoch.
Worked example: One example (x = 2, y = 7). Start w = 1, b = 0, α = 0.1. Do one gradient step.
ŷ = 2, error ŷ − y = −5. ∂L/∂w = 2(−5)(2) = −20, ∂L/∂b = 2(−5) = −10. New w = 1 − 0.1(−20) = 3, new b = 0 − 0.1(−10) = 1. Now ŷ = 3(2) + 1 = 7: perfect for this point.
w, b, lr = 0.0, 0.0, 0.01
for epoch in range(1000):
    pred = w * x + b                    # x, y are NumPy arrays
    err = pred - y
    w -= lr * 2 * (err * x).mean()      # step against the gradient
    b -= lr * 2 * err.mean()
Detailed explanationWhere the derivatives come from

L = (1/n) Σ (wxᵢ + b − yᵢ)². By the chain rule, the derivative of (stuff)² is 2·(stuff)·(derivative of stuff). The derivative of (wxᵢ + b − yᵢ) with respect to w is xᵢ, and with respect to b it's 1. So ∂L/∂w = (2/n) Σ (ŷᵢ − yᵢ)xᵢ and ∂L/∂b = (2/n) Σ (ŷᵢ − yᵢ).

2.5Beyond straight lines

"Linear" means linear in the weights, not necessarily in the original inputs. Add new features made from old ones and a linear model can fit curves:

Polynomial features

Use x, x², x³ as three features: ŷ = w₁x + w₂x² + w₃x³ + b. Still linear regression, but the fit is a cubic curve.

Interactions

x₁·x₂ lets the effect of one feature depend on another (sunshine helps ice cream sales more when it's also hot).

Logs

log(income) when doubling matters more than adding a fixed amount.

Domain knowledge

Distance from the city center may predict rent better than raw latitude and longitude.
Correlation is not causationA model can predict well from a feature that doesn't cause the outcome. Ice cream sales predict drownings (both go up in summer). A predictive model answers 'what will happen', not 'what should we change'.

Unit summary

Model

ŷ = w · x + b. Each weight = change in ŷ per unit of that feature, holding others fixed.

Loss

MSE = mean of (ŷ − y)². RMSE in y's units, MAE robust to outliers, R² = share of variance explained.

Least squares

w = Σ(x − x̄)(y − ȳ) / Σ(x − x̄)², b = ȳ − w x̄. Line passes through (x̄, ȳ).

Gradient descent

w ← w − α ∂L/∂w. α too small = slow, too big = diverges. Mini-batch SGD; epochs. Feature engineering bends a linear model.
