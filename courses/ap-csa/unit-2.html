Core ideas

So far, every line of a program ran exactly once, top to bottom. Unit 2 changes that. Selection (if statements) lets a program choose which lines run. Iteration (loops) lets it repeat lines.

Exam weight

Unit 2 is 25–35% of the exam, the second largest unit. Loop tracing appears in many multiple-choice questions, and free-response question 1 always uses loops and if statements.

The main skill

Tracing loops: keep a table with one row per pass through the loop. Count passes carefully, especially the first and last.

2.1–2.2Boolean expressions

Comparisons that produce true or false.

A boolean expression evaluates to true or false. Relational operators compare two values:

OperatorMeaningExample (x = 5)
==equal tox == 5 → true
!=not equal tox != 5 → false
<, <=less than, at mostx < 5 → false, x <= 5 → true

Common mistakes= stores; == compares. For objects (including Strings), == checks whether two references point to the same object; use equals to compare contents.

2.3–2.4if, else and else if

Choosing which code runs.

if (condition)
{
    // runs only when condition is true
}
else
{
    // runs only when condition is false
}

An if-else-if chain checks conditions from the top and runs only the first branch whose condition is true; the rest are skipped.

Separate ifs vs else if

int x = 95;
if (x > 90) System.out.print("A");
if (x > 80) System.out.print("B");   // separate if: also checked

Prints AB. With else if on the second line, it would print only A.

Worked example: What is printed when score is 70? When it's 69?
70: 70 ≥ 90 false, 70 ≥ 80 false, 70 ≥ 70 true → C. 69: all three false → the else runs → F.
BracesWithout braces, an if controls only the next single statement. Indentation doesn't matter to Java.
Detailed explanationNested ifs and dangling else

Nested if statements

An if inside another if runs only when both conditions hold. if (a) { if (b) {...} } behaves like if (a && b) {...}, but nesting lets you add an else that applies only when a is true and b is false.

Which if does an else belong to?

Without braces, an else belongs to the nearest unmatched if above it, regardless of indentation. Exam questions sometimes indent code misleadingly to test this.

Order matters in a chain

In an else-if chain, put the most specific (narrowest) conditions first. If score >= 70 came first, a score of 95 would get a C.

2.5Compound boolean expressions

and, or, not, and short-circuiting.

OperatorNameTrue when
&&andboth sides are true
||orat least one side is true
!notthe expression is false

Order: ! first, then &&, then ||. So a || b && c means a || (b && c).

Short-circuit evaluation

Java stops as soon as the answer is known. With &&, if the left side is false, the right side is never evaluated. With ||, if the left side is true, the right side is skipped.

if (x != 0 && 10 / x > 1)   // safe: if x is 0, the division never happens

This is how you guard against errors: check that something is safe before using it, on the left side of &&.

2.6Equivalent boolean expressions and De Morgan's laws

Rewriting conditions without changing their meaning.

!(a && b) ≡ !a || !b      !(a || b) ≡ !a && !b

To push a ! inside parentheses: negate each part and flip && and ||. Negating a comparison flips it: !(x < 5) is x >= 5, and !(x == y) is x != y.

Worked example: Simplify !(x > 3 && y <= 10).
Negate each part and flip &&: !(x > 3) is x <= 3, !(y <= 10) is y > 10. Result: x <= 3 || y > 10.

To check whether two expressions are equivalent, use a truth table: try every combination of true and false and compare the results.

Common mistakeNegating x < 5 as x > 5. It's x >= 5: the opposite of "less than" includes equal.
Detailed explanationWhy De Morgan's laws work

In words

"Not (raining and cold)" means at least one of them is false: not raining, or not cold. "Not (raining or cold)" means neither: not raining and not cold.

Truth tables

With two variables there are only 4 combinations (TT, TF, FT, FF). With three, 8. Writing them out is the most reliable way to check equivalence on the exam.

Comparing objects

Two references are equal with == only if they point to the same object. Two different String objects with the same characters are equals but not ==. Use equals for content; use == null to check whether a reference points nowhere.

2.7while loops

Repeat while a condition is true.

while (condition)
{
    // body: repeats as long as condition is true
}

Java checks the condition; if it's true, the body runs, then Java goes back and checks again. When the condition is false, the loop ends and the program continues after it. If the condition is false the first time, the body never runs.

Worked example: What does the code above print?
Passes: sum 2 (num 47), sum 9 (num 4), sum 13 (num 0). num > 0 is now false, so it prints 13.

Infinite loops

If nothing in the body moves the condition toward false, the loop never ends:

int i = 0;
while (i < 10)
{
    System.out.println(i);   // forgot i++: prints 0 forever
}

Sentinel and flag loops

A loop can run until a special value appears (a sentinel) or until a boolean flag changes. That's useful when you don't know the number of passes in advance.

Detailed explanationDesigning a while loop

Three parts

Every loop needs (1) initialization before it, (2) a condition, and (3) an update inside the body that eventually makes the condition false. Missing the update is the usual cause of infinite loops.

Off by one

The most common loop bug is running one time too many or too few. Check the first pass and the last pass by hand: what is the variable's value when the body runs for the last time?

Return inside a loop

A return statement inside a loop ends the whole method immediately, which ends the loop too. This is common in search methods: return as soon as you find the answer, and return a "not found" value after the loop.

2.8for loops

Counting loops in one line.

for (initialize; condition; update)
{
    body
}

A for loop puts the three parts of a counting loop on one line. The order is: initialize once, then check the condition, run the body, update, check again, and so on.

The same loop as a while loop:

int i = 1;
while (i <= 4)
{
    total += i * i;
    i++;
}

Counting passes

  • for (int i = 0; i < n; i++) runs n times (i = 0 … n−1).
  • for (int i = 1; i <= n; i++) runs n times (i = 1 … n).
  • for (int i = a; i < b; i++) runs b − a times; with <=, b − a + 1 times.
ScopeA variable declared in the for header (like int i) exists only inside the loop. Using i after the loop is a compile error.

2.9Standard algorithms with loops

Sum, count, min/max, divisibility.

A handful of patterns cover most loop questions. Learn their shape and you can write them quickly in a free-response answer.

Sum and average

Start a total at 0, add each value, divide by the count at the end (as a double).

Count

Start a counter at 0; inside the loop, if (condition) count++;

Minimum / maximum

Start with the first value (not 0), and replace it whenever you find a bigger (or smaller) one.

Divisibility and digits

n % k == 0 tests divisibility; n % 10 and n / 10 take apart digits.

public static int countMultiples(int n, int k)
{
    int count = 0;
    for (int i = 1; i <= n; i++)
    {
        if (i % k == 0)
            count++;
    }
    return count;
}
Worked example: What does countMultiples(20, 3) return?
Multiples of 3 from 1 to 20: 3, 6, 9, 12, 15, 18. Returns 6.
Common mistakeStarting a maximum at 0. If all the values are negative, the answer would wrongly be 0. Start with the first value, or with Integer.MIN_VALUE.
Detailed explanationWriting algorithms from a description

Start with the result variable

Decide what the method returns, declare a variable for it, and give it a starting value that is correct if the loop never runs (0 for a count, true for "all", false for "any").

"Any" vs "all"

To check whether any value meets a condition, return true as soon as one does, and false after the loop. To check whether all do, return false as soon as one fails, and true after the loop.

Averages

Divide only after the loop, and avoid int division: (double) sum / count. If the count could be 0, check first.

2.10String algorithms

Reverse, count, find and build Strings.

Loops over Strings visit each index from 0 to length() - 1 and look at one character at a time with substring(i, i + 1).

public static String reverse(String s)
{
    String result = "";
    for (int i = s.length() - 1; i >= 0; i--)
    {
        result += s.substring(i, i + 1);
    }
    return result;
}
public static int countLetter(String s, String letter)
{
    int count = 0;
    for (int i = 0; i < s.length(); i++)
    {
        if (s.substring(i, i + 1).equals(letter))
            count++;
    }
    return count;
}
Worked example: What does countLetter("banana", "a") return?
Indexes 1, 3 and 5 hold "a": returns 3.

Finding a substring

To check every position for a word of length k, the loop must stop at s.length() - k, so substring(i, i + k) never goes past the end:

for (int i = 0; i <= s.length() - k; i++)
{
    if (s.substring(i, i + k).equals(word))
        ...
}
Common mistakei <= s.length() with substring(i, i + 1) goes one past the end and throws StringIndexOutOfBoundsException on the last pass.

2.11Nested iteration

Loops inside loops.

A loop inside a loop: for each pass of the outer loop, the inner loop runs all of its passes. The inner loop restarts from the beginning every time.

2.12Informal run-time analysis

Counting how many times code runs.

A statement execution count is how many times a line runs. Comparing counts tells you which algorithm does less work, especially as the input size n grows.

Worked example: How many times does count++ run?
int count = 0;
for (int i = 0; i < 5; i++)
    for (int j = 0; j < i; j++)
        count++;
i = 0: 0 times; i = 1: 1; i = 2: 2; i = 3: 3; i = 4: 4. Total 10.
  • One loop over n items: about n executions.
  • Two loops one after the other: about 2n, still grows like n.
  • A loop nested inside another, each over n: about n². Doubling n quadruples the work.
Exam styleQuestions ask for an exact count for specific numbers, or which code segment runs a statement more times. Count the passes of each loop separately, then multiply (nested) or add (one after the other).

Free response: methods and control structures

How Unit 2 shows up in free response.

Free-response question 1 gives you a scenario and asks you to write one or two methods using loops and if statements, often calling other methods that are described for you. A reliable process:

  1. Read the header: what does it return, what are the parameters?
  2. Work one example from the prompt by hand and notice what you're keeping track of.
  3. Declare those variables, then write the loop, then the if statements, then the return.
  4. Check the first and last loop passes for off-by-one errors.
Worked example: Write longestRun(s, ch): the length of the longest stretch of consecutive copies of the one-letter String ch in s. longestRun("aabaaab", "a") returns 3.
public static int longestRun(String s, String ch)
{
    int best = 0;
    int current = 0;
    for (int i = 0; i < s.length(); i++)
    {
        if (s.substring(i, i + 1).equals(ch))
        {
            current++;
            if (current > best)
                best = current;
        }
        else
        {
            current = 0;
        }
    }
    return best;
}
Keep the current run length, reset it when a different letter appears, and remember the best seen so far.
ScoringGraders award points for each part of the algorithm: the loop visiting every element, the correct comparison, updating the right variables, and returning (not printing) the result. A working but slightly different approach still earns full credit.

Common mistakes

Points students lose most often.

  1. Off-by-one: < vs <=, starting at 0 vs 1.
  2. Forgetting the update and writing an infinite loop.
  3. Using separate ifs when only one branch should run (else if).
  4. Negating < as > instead of >=.
  5. Putting the risky check before the guard: 10 / x > 1 && x != 0 crashes when x is 0.
  6. Returning inside a loop too early ("return false" in the else of a search loop).
  7. Comparing Strings with ==.
