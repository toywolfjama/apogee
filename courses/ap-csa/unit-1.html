Core ideas

A Java program is a list of instructions that run from top to bottom. Each instruction stores a value, computes something, or calls a method. Unit 1 is about the building blocks: variables and types, expressions, calling methods, creating objects, and working with Strings.

Exam weight

Unit 1 is 15–25% of the AP exam. Almost every multiple-choice question in the other units also needs these skills, especially tracing code by hand.

The main skill

Tracing: keeping track of every variable's value as each line runs. Write a small table on scratch paper and update it line by line.

1.1Algorithms, programs and compilers

How code becomes a running program, and the three kinds of errors.

An algorithm is a step-by-step process to solve a problem. A program is an algorithm written in a programming language. Java code is turned into something the computer can run by a compiler, which also checks the code's grammar.

Kind of errorWhen it appearsExample
Syntax (compile-time) errorThe compiler refuses to build the program.Missing semicolon, misspelled keyword, storing a String in an int
Run-time error (exception)The program compiles, then crashes while running.Dividing an int by 0, calling a method on null, a bad String index
Logic errorIt runs, but gives the wrong answer.Using < instead of <=, adding when you meant to multiply

Output

System.out.println(x) prints x and then moves to a new line. System.out.print(x) prints x and stays on the same line.

System.out.print("A");
System.out.println("B");
System.out.println("C");

Output:

AB C
Detailed explanationCompiling, running and finding errors

What the compiler does

The compiler reads your whole source file and translates it into bytecode. It refuses if any line breaks Java's rules, and it reports the first problems it finds. Nothing runs until every compile error is fixed.

Exceptions

An exception is Java's way of stopping a program that tried something impossible while running: ArithmeticException (integer division by zero), NullPointerException (using a reference that points to nothing), StringIndexOutOfBoundsException (a bad index). The program stops at that line unless the exception is handled.

Logic errors are the hardest

The computer can't detect them. You find them by testing with inputs whose answers you already know, especially edge cases like 0, 1, negative numbers and empty Strings.

On the exam

Questions often ask what happens when code runs. Check in this order: does it compile? does it crash? if not, trace the output.

1.2Variables and data types

Choosing a type, declaring and assigning.

A variable is a named storage location. Every variable has a type that decides what it can hold. Declaring a variable gives it a type and name; assigning gives it a value.

TypeHoldsExamples
intwhole numbers0, -12, 2147483647
doublenumbers with decimals2.5, -0.1, 3.0
booleantrue or falsetrue, false
String (a reference type)text"Ada", ""

int, double and boolean are primitive types: the variable holds the value itself. String and every class are reference types: the variable holds a reference (an arrow) to an object.

int a = 5;
double b = 2.5;
boolean done = false;
String name = "Ada";
System.out.println(a + " " + b + " " + done + " " + name);
5 2.5 false Ada

A final variable is a constant: once assigned, it can't change. By convention its name is in capitals: final int MAX_TRIES = 3;

Common mistakeAn int can be stored in a double (double d = 5; stores 5.0), but a double can't be stored in an int without a cast: int x = 2.5; is a compile error.
Detailed explanationPrimitive vs reference, and naming rules

Why two kinds of types?

Primitives are small, fixed-size values (an int is 32 bits). Objects can be large and complicated, so the variable stores only the object's address. This difference explains aliasing and == vs equals, which come up later in this unit.

Naming

Names can contain letters, digits, _ and $, can't start with a digit, and can't be keywords like int or class. Java style uses camelCase: totalScore, numStudents. Names are case-sensitive: score and Score are different variables.

Declaring twice

A variable can be declared only once in the same block. int x = 3; int x = 4; is a compile error; the second line should be x = 4;.

Using a variable before giving it a value

A local variable that has been declared but not assigned can't be used: the compiler reports "variable might not have been initialized".

1.3Expressions and output

Operators, integer division, % and joining Strings.

Arithmetic operators: + - * / %. Java follows the usual order of operations: * / % before + -, left to right, with parentheses first.

Integer division and remainder

When both operands are ints, / gives an int: the decimal part is cut off (not rounded). % (modulus) gives the remainder.

ExpressionValueWhy
7 / 23int / int: 3.5 truncated
7.0 / 23.5a double is involved
7 % 217 = 2·3 + 1
2 % 727 goes in 0 times, remainder 2
-7 / 2-3truncates toward zero

String concatenation

+ with a String joins text. It's evaluated left to right, so the order matters:

System.out.println(1 + 2 + "3" + 4 + 5);
3345

1 + 2 is 3 (both ints), then "3" + "3" is "33", then "334", then "3345".

Escape sequences

Inside a String: \" is a quote, \\ is a backslash, \n is a new line.

Worked example: What does System.out.println(17 % 5 + 17 / 5 * 2); print?
17 % 5 = 2. 17 / 5 = 3 (int division), times 2 = 6. 2 + 6 = 8.
Common mistakeint / int by zero throws ArithmeticException, but double / 0 gives Infinity. AP questions use the int case.
Detailed explanationUsing % in real code

Even or odd

n % 2 == 0 is true for even n. Odd numbers give a remainder of 1 (or −1 for negative n), so test n % 2 != 0 for odd.

Digits

n % 10 is the last digit; n / 10 removes the last digit. Repeating both in a loop (Unit 2) takes a number apart digit by digit.

Wrapping around

(i + 1) % size cycles 0, 1, 2, …, size−1, 0, … which is handy for clocks and turns.

Divisibility

a % b == 0 means b divides a evenly.

1.4Assignment statements and input

= means store, and the right side is evaluated first.

The assignment operator = means "store": evaluate the right side, then put the value in the variable on the left. It is not a statement that two things are equal.

x = x + 1;   // take x, add 1, store the result back in x

The value on the right is computed using the current values of the variables, before anything changes.

Input

Programs can read keyboard input with the Scanner class. The AP exam does not test keyboard input; values usually come in as method parameters.

Tracing tipWrite each variable at the top of a column. Each time a line assigns, cross out the old value and write the new one below it. Never update in your head.

1.5Casting and range of variables

Converting between int and double.

A cast converts a value to another type: (int) or (double) in front of a value.

(int) on a double

Cuts off the decimal part (truncates toward zero). (int) 3.99 is 3; (int) -3.99 is -3.

(double) on an int

Gives the same number as a double: (double) 7 is 7.0. Use it to force real division.

System.out.println((double) 7 / 2);    // cast happens first: 7.0 / 2 = 3.5
System.out.println((double) (7 / 2));  // 7 / 2 = 3 first, then 3.0
3.5 3.0

Rounding

To round a positive double to the nearest int: (int) (x + 0.5). For a negative double: (int) (x - 0.5).

Range and overflow

An int is stored in 32 bits, so it can only hold values from Integer.MIN_VALUE (−2,147,483,648) to Integer.MAX_VALUE (2,147,483,647). Going past the end overflows and wraps around to the other end without any error.

int big = Integer.MAX_VALUE;
big = big + 1;   // now equals Integer.MIN_VALUE

Doubles are stored approximately, so some decimals can't be represented exactly: 0.1 + 0.2 prints 0.30000000000000004.

Detailed explanationWhen Java converts automatically

Widening is automatic

An int fits inside a double without losing anything, so Java converts automatically when you store an int in a double or mix them in arithmetic: 5 + 2.0 is 7.0.

Narrowing needs a cast

A double can lose its decimal part when it becomes an int, so Java makes you write the cast to show you mean it.

Where the cast applies

A cast applies only to the value right after it. (int) 2.5 * 2 is 2 * 2 = 4, but (int) (2.5 * 2) is 5. Use parentheses to cast a whole expression.

Averages

The classic bug: int sum = 7, count = 2; double avg = sum / count; gives 3.0, because the int division happens before the value is stored. Fix: (double) sum / count.

1.7–1.8APIs, libraries and documentation

Using code other people wrote.

A library is a collection of classes someone else wrote. An API (application program interface) is the documentation that tells you what those classes do and how to call their methods, without showing their code. You use String and Math this way: you know what Math.sqrt does without seeing how.

A class defines a type: the attributes (data) each object has and the behaviors (methods) it can perform.

Comments

// a single-line comment
/* a comment that can
   span several lines */
/** A Javadoc comment, used to document a method
 *  @param n the number of items (precondition: n > 0)
 *  @return the average
 */

A precondition is something that must be true before a method is called; the method doesn't have to check it. A postcondition is something that will be true after the method finishes (often describing the return value).

FRQ noteIf a free-response question states a precondition (for example, "n is positive"), you can assume it. You don't need extra code to check it.

1.9–1.10Method signatures and calling methods

Reading a method header and calling it correctly.

A method is a named block of code. Its signature is its name and its parameter list. The header also shows its return type.

public static double average(int a, int b)

Return type

double: the call produces a double value. void means it returns nothing.

Parameters

int a, int b: the method needs two ints, in that order.

Arguments

The actual values you pass: average(3, 8). They are copied into the parameters.

Calling methods

  • A void method is called as its own statement: printReport();
  • A non-void method returns a value you should use: double avg = average(3, 8); or System.out.println(average(3, 8));
  • Class (static) methods are called with the class name: Math.sqrt(16). Inside the same class, the name alone works.

Overloading

Several methods can share a name if their parameter lists differ (in number, type or order of types). Java picks the one that matches the arguments: Math.abs(-3) returns int 3 and Math.abs(-3.0) returns double 3.0.

Common mistakeCalling a non-void method and ignoring the result: Math.sqrt(x); compiles but does nothing useful. The value must be stored or used.
Detailed explanationParameters are copies

Pass by value

When you call a method, each argument's value is copied into the matching parameter. If the method changes its parameter, the caller's variable doesn't change. For objects, the copy is a copy of the reference, so the method can change the object both variables point to (Unit 3 goes deeper).

Matching arguments

The number of arguments must match, and each must be compatible with its parameter's type. An int argument works for a double parameter (widening), but a double argument doesn't work for an int parameter.

Return values flow back

A call like average(3, 8) is replaced by its return value when the expression is evaluated, so average(3, 8) * 2 works like any number.

Random integers in a range

To get a random int from low to high inclusive:

int r = (int) (Math.random() * (high - low + 1)) + low;
Worked example: Write an expression for a random die roll from 1 to 6.
Range size = 6 − 1 + 1 = 6. (int) (Math.random() * 6) + 1. Math.random() * 6 is in [0, 6); casting gives 0–5; adding 1 gives 1–6.
Common mistake(int) Math.random() * 6 is always 0: the cast applies to Math.random() first (giving 0), then 0 * 6.
Detailed explanationWhy the random formula works

Stretch, shift, cut

Math.random() gives a double in [0, 1). Multiplying by the number of possible values (high − low + 1) stretches it to [0, count). Casting to int gives one of 0, 1, …, count − 1, each equally likely. Adding low shifts the range to low … high.

Checking a formula

Plug in the extremes: the smallest Math.random() can be is 0, the largest is just under 1. For (int) (Math.random() * 10) + 5: smallest 0 + 5 = 5, largest (int) 9.99… + 5 = 14. Range 5–14.

pow and sqrt always return doubles

Math.pow(2, 3) prints 8.0, not 8. To store it in an int, cast: (int) Math.pow(2, 3).

1.12–1.13Objects: instances of classes

Classes, objects, constructors and references.

A class is a blueprint. An object is one thing built from that blueprint, with its own values for each attribute. Point is a class; a point at (2, 5) is an object of that class (an instance).

Objects are created with new and a constructor, which sets up the new object's starting values:

Point p = new Point(2, 5);

The variable p doesn't contain the object; it holds a reference to where the object lives in memory.

Constructors and overloading

A class can have several constructors with different parameter lists. new Point() might make (0, 0), while new Point(2, 5) uses the given values. Arguments must match one constructor's parameters in number, order and type.

null

A reference variable that doesn't point to any object holds null. Calling a method through a null reference throws a NullPointerException.

Detailed explanationWhat new actually does

Three steps

new Point(2, 5) (1) sets aside memory for a new Point object, (2) runs the constructor to fill in its attributes, (3) produces a reference to it. The assignment then stores that reference in the variable.

Aliasing

After Point q = p; there's still only one object. Changing it through q is visible through p. That's the main difference from primitives: int b = a; copies the number itself.

Garbage collection

When no variable refers to an object anymore, Java eventually reclaims its memory automatically.

Default values

An object's attributes that aren't set by the constructor get defaults: 0 for int, 0.0 for double, false for boolean, null for references.

1.14Calling instance methods

The dot operator on an object.

An instance method belongs to an object and is called with the dot operator on a reference: p.moveRight(4). It can read and change that object's own attributes.

class Point {
    private int x;
    private int y;
    public Point(int x, int y) { this.x = x; this.y = y; }
    public int getX() { return x; }
    public void moveRight(int d) { x += d; }
}
Point p = new Point(1, 1);
p.moveRight(4);        // void: changes p's x to 5
int a = p.getX();      // non-void: returns 5
System.out.println(a * 2);
10

Class method

Called on the class: Math.sqrt(9). Doesn't need an object.

Instance method

Called on an object: p.getX(), name.length(). Uses that object's data.

Common mistakeCalling an instance method with the class name: Point.getX() is a compile error, because Java doesn't know which point you mean.

1.15String manipulation

Indexes, substring, indexOf, equals and compareTo.

A String is an object holding a sequence of characters. Each character has an index, starting at 0. The last index is length() - 1.

Method (Java Quick Reference)Returns
int length()number of characters
String substring(int from, int to)characters from index from up to but not including to
String substring(int from)from index from to the end
int indexOf(String str)index of the first occurrence of str, or −1 if not found
boolean equals(String other)true if the characters are exactly the same
int compareTo(String other)negative if this comes first alphabetically, 0 if equal, positive if after

One character

To get the character at index i as a String: s.substring(i, i + 1).

Strings are immutable

No String method changes a String. Methods like substring return a new String. To "change" s, assign the result back: s = s.substring(1);

== vs equals

For objects, == checks whether two references point to the same object. To compare text, always use equals.

Worked example: Given String w = "banana";, what is w.substring(w.indexOf("n"), w.length() - 1)?
indexOf("n") = 2. length() − 1 = 5. substring(2, 5) = characters at 2, 3, 4 = "nan".
Common mistakessubstring(a, b) has length b − a. An index equal to length() is allowed as the end of substring, but not as a start for a one-character substring. Going past it throws StringIndexOutOfBoundsException.
Detailed explanationcompareTo and String details

How compareTo decides

It compares character by character from the left. At the first difference, it returns the difference of the two characters' codes. If one String runs out first, the shorter one comes first. Uppercase letters come before lowercase ("Zebra" comes before "apple"). Only the sign of the result matters on the exam.

Concatenation with other types

"Score: " + 90 is "Score: 90". Any value joined with a String becomes text, and objects use their toString method.

Finding every occurrence

Combining indexOf and substring in a loop (Unit 2) lets you count or remove every copy of a word: find it, record it, then search again in the part after it.

Empty String

"" has length 0. s.substring(s.length()) is legal and gives "".

Tracing questions and free response

How Unit 1 shows up on the exam.

The AP exam has 42 multiple-choice questions and 4 free-response questions, all on the computer. Unit 1 skills appear in nearly every question. Three habits earn points:

  1. Trace on paper. Make a table with a column per variable and update it line by line.
  2. Check types at every step. Is this division int / int? Is this + joining Strings?
  3. Check compile and run-time problems first: wrong type stored, method called on the class instead of an object, bad substring index, null reference.

Free-response question 1: Methods and Control Structures

You write method bodies that call other methods described in the problem. Read each method's header carefully: its return type tells you whether to store the result, and its parameters tell you what to pass.

// Given: public static int getScore(String name)   returns a player's score
// Write: average of two players' scores, as a double
public static double averageScore(String a, String b)
{
    int total = getScore(a) + getScore(b);
    return total / 2.0;
}
Free-response scoringYou lose points for calling methods incorrectly (wrong number or type of arguments), for losing precision with int division, and for printing instead of returning. Small syntax slips like a missing semicolon usually aren't penalized.

Common mistakes

Points students lose most often.

  1. Forgetting int division: 5 / 2 is 2, and (double) (5 / 2) is 2.0.
  2. Thinking (int) rounds. It truncates: (int) 2.9 is 2.
  3. substring's second index is excluded; indexes start at 0.
  4. Comparing Strings with == instead of equals.
  5. Expecting a String method to change the String. Strings are immutable; store the result.
  6. Ignoring the return value of a non-void method.
  7. Calling a method on null (NullPointerException).
  8. Reading "1" + 2 + 3 as "6". It's "123"; but 1 + 2 + "3" is "33".
