Parabolas and quadratics

Vertex form, factoring, completing the square, the quadratic formula and the discriminant.

3.1Three forms of a quadratic

A quadratic makes a U-shaped parabola. Each form shows you something different at a glance.

FormEquationRead off
Standardy = ax² + bx + cy-intercept c; axis x = −b/(2a)
Vertexy = a(x − h)² + kvertex (h, k)
Factoredy = a(x − r)(x − s)x-intercepts r and s

The sign of a decides the direction: a > 0 opens up (minimum), a < 0 opens down (maximum). Bigger |a| means narrower.

3.2Solving quadratic equations

Four ways to solve ax² + bx + c = 0. Pick the fastest:

  1. Factor and use the zero-product rule: if AB = 0, then A = 0 or B = 0.
  2. Square roots when there's no x term: x² = 49 → x = ±7.
  3. Complete the square (this is how you get vertex form).
  4. Quadratic formula always works: x = (−b ± √(b² − 4ac)) / (2a).
x = (−b ± √(b² − 4ac)) / 2a
Worked example: Solve 2x² − 3x − 5 = 0.
a = 2, b = −3, c = −5. Discriminant 9 + 40 = 49. x = (3 ± 7)/4 → x = 5/2 or x = −1.

3.3The discriminant

The part under the root, D = b² − 4ac, tells you how many real solutions there are before you solve.

DReal solutionsGraph
D > 02crosses the x-axis twice
D = 01 (double)touches the x-axis at the vertex
D < 00 (two complex)misses the x-axis
Complex numbersWhen D < 0 the solutions use i = √−1. For example x² + 4 = 0 → x = ±2i. You'll see these again in precalc.

3.4Quadratics in the real world

Projectile height: h(t) = −16t² + v₀t + h₀ (feet), or −4.9t² + … in meters. The vertex is the max height; the positive zero is when it lands.

Worked example: A ball is thrown up at 64 ft/s from 20 ft. Max height?
Vertex at t = −64/(2·−16) = 2 s. h(2) = −64 + 128 + 20 = 84 ft.

Unit summary

Forms

Standard (c, axis −b/2a), vertex (h, k), factored (zeros).

Solve

Factor · square roots · complete the square · quadratic formula.

Discriminant

b² − 4ac: positive → 2, zero → 1, negative → 0 real solutions.

Vertex

x = −b/(2a). Plug back in for the max or min value.
