Before Precalc · Unit 1

The algebra toolkit

Order of operations, exponents, radicals and factoring: the moves you'll use on every single precalc problem.

1.1Order of operations

Every calculation follows the same order, so everyone gets the same answer: Parentheses, Exponents, Multiplication and Division (left to right), Addition and Subtraction (left to right).

Common trap−3² means −(3²) = −9. Only (−3)² = 9. The exponent grabs the number right next to it, not the minus sign.

1.3Radicals

√x is the non-negative number whose square is x. To simplify, pull out perfect-square factors: √(ab) = √a · √b.

Not allowed√(a + b) is NOT √a + √b. Check: √(9 + 16) = √25 = 5, but √9 + √16 = 7.

1.4Factoring

Factoring is multiplication run backwards. Always try these in order:

  1. GCF first. 6x² + 9x = 3x(2x + 3).
  2. Difference of squares: a² − b² = (a − b)(a + b). So x² − 49 = (x − 7)(x + 7).
  3. Trinomial x² + bx + c: find two numbers that multiply to c and add to b.
  4. Trinomial ax² + bx + c: AC method: multiply a·c, split the middle term, factor by grouping.
  5. Cubes: a³ ± b³ = (a ± b)(a² ∓ ab + b²).

1.5Rational expressions

A rational expression is a fraction of polynomials. Simplify by factoring first, then cancelling common factors (never cancel terms that are added).

Worked example: Simplify (x² − 9) / (x² + 5x + 6).
Factor: (x − 3)(x + 3) / ((x + 2)(x + 3)). Cancel (x + 3): (x − 3)/(x + 2), with x ≠ −3 and x ≠ −2.
Worked example: Add 1/x + 2/(x + 1).
Common denominator x(x + 1): (x + 1 + 2x) / (x(x + 1)) = (3x + 1)/(x(x + 1)).
Cancelling terms(x + 3)/3 is NOT x. You can only cancel factors (things multiplied), not terms (things added).

Unit summary

Order

Parentheses → exponents → × ÷ left to right → + − left to right. −3² = −9.

Exponents

Add when multiplying, subtract when dividing, multiply for a power of a power. x⁰ = 1, x⁻ⁿ = 1/xⁿ, x1/n = ⁿ√x.

Radicals

Pull out perfect squares; rationalize denominators. √(a + b) ≠ √a + √b.

Factoring

GCF → difference of squares → trinomials (AC method) → cubes. Check by multiplying back out.
