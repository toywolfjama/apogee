Sequences, exponential growth and decay, inverses, logarithms, log equations and semi-log plots.

2.1Arithmetic and geometric sequences (2.1–2.2)

Arithmetic

Add the same common difference d: aₙ = a₀ + dn. Like a linear function on whole numbers.

Geometric

Multiply by the same common ratio r: gₙ = g₀·rⁿ. Like an exponential function on whole numbers.

Linear functions change by equal differences over equal input steps. Exponential functions change by equal ratios. That one sentence decides most modeling questions.

The orange row shows the ratio of consecutive exponential outputs: always r. Eventually any increasing exponential beats any linear function.

2.7Composition and inverses (2.7–2.8)

f and g are inverses when f(g(x)) = x and g(f(x)) = x. The input-output pairs swap, so the graphs reflect over y = x.

2.9Logarithms (2.9–2.12)

A logarithm answers "what exponent?": logb c = a means ba = c. So log₂ 8 = 3 because 2³ = 8. ln means log base e; log with no base means base 10.

Log functions f(x) = a·logbx: domain x > 0, vertical asymptote x = 0, range all reals. With b > 1 they increase and are concave down: output grows by equal amounts when input is multiplied by equal factors.

2.13Equations, modeling and semi-log plots (2.13–2.15)

Extraneous solutionsAlways plug log solutions back in. The argument of every log must be positive.

Semi-log plots put ln y (or log y) on the vertical axis. Exponential data y = abˣ become a straight line: ln y = ln a + x·ln b. Slope = ln b, intercept = ln a.

Unit summary

Linear vs exponential

Equal differences vs equal ratios over equal steps.

Exponential

a·bˣ: b > 1 growth, 0 < b < 1 decay; asymptote y = 0 (shifted by + k).

Logs

log_b c = a ⇔ bᵃ = c. Product → sum, quotient → difference, power → coefficient.

Solving

Isolate, rewrite, change of base. Check log arguments > 0. Semi-log: exponential → line.
