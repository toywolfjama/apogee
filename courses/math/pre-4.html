Before Precalc · Unit 4

All about functions

Notation, domain and range, transformations, composition and inverses: the language of precalc.

4.1What a function is

A function assigns each input exactly one output. f(x) is read "f of x": the output when the input is x. It is not multiplication.

Vertical line test

A graph is a function if no vertical line hits it twice. A circle fails; a parabola y = x² passes.

Evaluating

If f(x) = x² − 3x, then f(−2) = 4 + 6 = 10 and f(a + 1) = (a + 1)² − 3(a + 1).

Domain = every allowed input. Range = every output you actually get. Watch for two things that shrink a domain:

DangerExampleDomain
Division by zerof(x) = 1/(x − 2)x ≠ 2
Even root of a negativeg(x) = √(x + 5)x ≥ −5
Bothh(x) = 1/√(4 − x)x < 4

4.2Transformations

Every function family can be moved with the same four knobs: y = a·f(b(x − h)) + k.

ChangeEffect
f(x) + kshift up k
f(x − h)shift right h (inside is opposite!)
a·f(x)vertical stretch by a; negative a reflects over the x-axis
f(bx)horizontal squeeze by 1/b; negative b reflects over the y-axis
Inside moves the other wayf(x + 3) shifts LEFT 3, because you need x = −3 to feed the same input f(0) that x = 0 used to.

4.3Composition and inverses

Composition chains functions: (f ∘ g)(x) = f(g(x)). Do the inside one first.

An inverse f⁻¹ undoes f: if f(2) = 5, then f⁻¹(5) = 2. To find it: swap x and y, then solve for y. Its graph is the mirror image across y = x.

One-to-oneOnly functions that pass the horizontal line test have inverses. y = x² fails, so we restrict it to x ≥ 0 to get √x.

Unit summary

Domain

No dividing by 0, no even roots of negatives.

Transformations

a·f(b(x − h)) + k: outside moves are what they look like; inside moves are opposite and 1/b.

Composition

f(g(x)): inside first. Usually f(g(x)) ≠ g(f(x)).

Inverse

Swap x and y, solve. Mirror over y = x. f(f⁻¹(x)) = x.
