Boolean logic

Gates, truth tables, Boolean algebra, De Morgan's laws and Karnaugh maps: how to design the smallest circuit for any rule.

3.1Logic gates

A logic gate takes one or more bits in and produces one bit out. Gates are built from a handful of transistors (unit 1), and every digital circuit, including a whole CPU, is gates wired together.

+ is not additionIn Boolean algebra, + means OR, so 1 + 1 = 1. And · means AND. Read A + B as "A or B".

A truth table lists the output for every combination of inputs. With n inputs there are 2ⁿ rows. Write the rows in binary counting order (000, 001, 010, …) so you never miss one.

3.2Boolean algebra

Boolean algebra lets you simplify a circuit on paper before you build it. Fewer gates means a cheaper, faster, cooler chip.

De Morgan's laws are the most important: to push a NOT through a group, flip AND ↔ OR and complement each variable. "Not (raining and cold)" is the same as "not raining or not cold".

Check with a truth tableAny two Boolean expressions are equal if and only if their truth tables match on every row. When in doubt, build both tables.
Detailed explanationProving A + A′B = A + B

A + A′B = (A + A′)(A + B) by the OR-distributive law = 1 · (A + B) = A + B. Or check all four rows: (0,0) → 0 and 0; (0,1) → 1 and 1; (1,0) → 1 and 1; (1,1) → 1 and 1. ✓

3.3From truth table to circuit

Any truth table can be turned into a circuit with this recipe, called sum of products (SOP):

  1. Find every row where the output is 1. Each one is a minterm.
  2. Write an AND term for that row: use the variable if it's 1 in that row, its complement if it's 0.
  3. OR all the terms together.
Worked example: Build the majority function M(A, B, C): output 1 when at least two inputs are 1.
Rows with output 1: 011, 101, 110, 111 (minterms 3, 5, 6, 7). SOP: M = A′BC + AB′C + ABC′ + ABC. Simplified (see K-maps below): M = AB + AC + BC.

The dual recipe, product of sums (POS), uses the rows where the output is 0 (maxterms): write an OR term that is 0 on that row (the variable if it's 0, its complement if it's 1), then AND them. POS is shorter when the output has fewer 0s than 1s.

Shorthand: F(A, B, C) = Σm(3, 5, 6, 7) lists the minterms, and F = ΠM(0, 1, 2, 4) lists the maxterms. They describe the same function.

3.4Karnaugh maps

A K-map is a truth table folded into a grid so that neighbouring cells differ in exactly one variable. The columns are in Gray code order (00, 01, 11, 10), not counting order. That way, any two adjacent 1s can be merged and one variable disappears.

  1. Circle groups of 1s. Each group must be a rectangle with 1, 2, 4, 8 or 16 cells.
  2. Make groups as large as possible; bigger groups mean fewer variables.
  3. Groups may overlap, and they wrap around the edges (the left and right columns are neighbours, so are the top and bottom rows, and so are the four corners).
  4. Use as few groups as possible while covering every 1.
  5. For each group, keep only the variables that stay the same across the whole group.

A group of 2ᵏ cells eliminates k variables. In a 4-variable map: a pair gives a 3-literal term, a quad gives 2 literals, an octet gives 1.

Don't-care conditionsSometimes an input combination can never happen, like the codes 10–15 in a circuit that only receives decimal digits 0–9. Mark those cells X and treat each one as a 1 if it helps you make a bigger group, or a 0 if it doesn't.

3.5Universal gates

NAND by itself can build any logic function, and so can NOR. That's why they're called universal. Chips are often built almost entirely from NAND gates because a NAND is the cheapest CMOS gate.

BuildFrom NAND only
NOT AA NAND A
A AND B(A NAND B) NAND (A NAND B)
A OR B(A NAND A) NAND (B NAND B) — De Morgan: (A′B′)′ = A + B

Bubble pushing: by De Morgan, a NAND gate is the same as an OR gate with inverted inputs, and a NOR is an AND with inverted inputs. A two-level AND-OR circuit can therefore be redrawn as NAND-NAND with no change in behaviour.

Unit summary

Gates

AND · OR + NOT ′, plus NAND, NOR, XOR (inputs differ), XNOR (inputs equal). n inputs → 2ⁿ truth-table rows.

Algebra

A + A′ = 1, A·A′ = 0, A + AB = A, A + A′B = A + B. De Morgan: (AB)′ = A′ + B′, (A + B)′ = A′B′.

SOP / POS

SOP: OR together an AND term for every 1 row. POS: AND together an OR term for every 0 row. Σm(…) and ΠM(…) shorthand.

K-maps

Gray-code order. Groups of 1, 2, 4, 8; as big as possible; may wrap and overlap. Keep the variables that don't change. NAND and NOR are universal.
