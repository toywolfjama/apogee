The hardware workshop

Flip bits, wire gates, write machine code and tune a cache. Each mission has a goal, hints if you need them, and up to three stars.

Mission 1Flip the switches

A register is a row of switches. Flip bits until the register holds each target number. The clock starts at your first click.

Mission 2Hex, negatives and letters

Same register, harder targets: hexadecimal, two's complement negatives and ASCII characters.

Mission 3One gate, one job

Pick the single gate whose output matches the target column.

Mission 4Build a half adder

Two outputs this time: the sum bit S and the carry bit C of A + B.

Mission 5De Morgan's trick

Make a NOR gate's truth table, but you can only use NOT on each input followed by one 2-input gate.

Mission 6The voting machine

Three judges vote (A, B, C). The light turns on when at least two vote yes.

Mission 7Boss level: the full adder

Add three bits A + B + Cin. Five gates, two outputs. This is the circuit inside every adder in your computer.

Mission 8Draw it on a K-map

Click cells in the Karnaugh map until the simplest expression is exactly F = AC.

Mission 9Your first program

Write machine instructions that output M[13] + M[14] − M[15].

Mission 10Make it loop

Output 3, 2, 1 using a loop (no copy-pasting three OUTs).

Mission 11Fix the cache conflict

Play the “conflict” sequence. In a direct-mapped cache addresses 0 and 4 fight over the same line. Change the layout to get a hit rate of at least 50%.
