Computer Engineering · Unit 4

Circuits that compute

Half and full adders, the ALU, multiplexers and decoders: the building blocks inside every processor.

4.1Adders: how a computer does arithmetic

A combinational circuit has outputs that depend only on its current inputs; it has no memory. The most important one in any computer is the adder.

Half adder: add two bits

Adding two bits gives a 2-bit answer: 0+0 = 00, 0+1 = 01, 1+1 = 10. The low bit is the sum S, the high bit is the carry C.

S = A ⊕ B      C = A · B

Full adder: add two bits plus a carry in

To add multi-bit numbers each column also needs the carry from the column to its right. A full adder has three inputs (A, B, Cin):

S = A ⊕ B ⊕ Cin      Cout = AB + Cin(A ⊕ B)

Ripple-carry adder

Chain n full adders, feeding each carry out into the next carry in, and you can add n-bit numbers. Here's a 2-bit version: inputs A₁A₀ + B₁B₀.

Ripple is slowEach full adder must wait for the carry from the one before it. In a 64-bit ripple adder the last sum bit can't settle until the carry has crawled through all 64 stages. Real CPUs use faster designs (below).

4.2Subtraction, the ALU and fast carries

Subtraction for free: A − B = A + B′ + 1 (two's complement). Put an XOR gate on each B input controlled by a signal SUB, and feed SUB into the first carry in. When SUB = 0 the XORs pass B through and Cin = 0 (add). When SUB = 1 the XORs invert B and Cin = 1 (subtract). One circuit does both.

The arithmetic logic unit (ALU) is the calculator at the heart of a CPU. It computes several results at once (sum, AND, OR, XOR, a comparison…) and a multiplexer picks the one the instruction asked for. It also produces flags:

FlagSet whenUsed for
Z (zero)the result is 0if a == b (compute a − b, check Z)
N (negative)the top bit of the result is 1if a < b for signed numbers
C (carry)there was a carry out of the top bitunsigned overflow, multi-word arithmetic
V (overflow)signed overflow happeneddetecting wrong signed results

Propagation delay and carry lookahead

Every gate takes a tiny time to respond, its propagation delay (a few picoseconds in a modern chip). The longest path from any input to any output is the critical path; it sets how fast the clock can tick.

For each bit position define generate G = AB (this column makes a carry by itself) and propagate P = A ⊕ B (this column passes an incoming carry along). Then

Ci+1 = Gi + PiCi

Expanding this, C₂ = G₁ + P₁G₀ + P₁P₀C₀, and so on: every carry can be computed directly from the inputs in two gate levels. A carry-lookahead adder does exactly that, trading extra gates for speed. Its delay grows like log n instead of n.

Worked example: A ripple-carry adder's full adder has a carry delay of 2 gate delays. How long until the final carry of a 32-bit adder is ready?
The carry passes through 32 stages: 32 × 2 = 64 gate delays. At 10 ps per gate that's 640 ps, which alone would limit the clock to about 1.5 GHz.

4.3Multiplexers: choosing between inputs

A multiplexer (MUX) is a digital switch. Its select inputs choose which data input is copied to the output. A 2:1 MUX has one select bit; a 4:1 MUX has two; an 2ⁿ:1 MUX has n.

2:1 MUX: Y = S′·D₀ + S·D₁

MUXes are everywhere in a CPU: picking which register feeds the ALU, choosing between PC + 4 and a branch target, selecting which ALU result to keep. A MUX can also implement any function directly: put the truth table's output column on the data inputs and the variables on the select lines.

Worked example: Implement F(A, B) = A ⊕ B with a 4:1 MUX.
Select lines = A, B. Data inputs D₀…D₃ = the truth table outputs 0, 1, 1, 0. Done, no other gates needed.

4.4Decoders, encoders and comparators

A decoder turns an n-bit code into 2ⁿ separate lines, exactly one of which is 1. Memory uses decoders to activate the one row that matches an address.

Encoder

The reverse: 2ⁿ input lines → n-bit code. A priority encoder outputs the code of the highest-numbered active input, used to decide which interrupt or request goes first.

Comparator

A = B for one bit is XNOR. For n bits, AND together all n XNORs. A > B and A < B come from subtracting and checking flags, or from a dedicated magnitude comparator.

7-segment decoder

Turns a 4-bit digit 0–9 into the 7 signals that light the segments of a display. Each segment is its own K-map problem, and codes 10–15 are don't-cares.

Demultiplexer

One input, many outputs: the select bits choose which output receives the data. It's a decoder with an enable input.

Unit summary

Adders

Half: S = A⊕B, C = AB. Full: S = A⊕B⊕Cin, Cout = AB + Cin(A⊕B). Ripple-carry = chain of full adders; delay grows with n.

ALU

A − B = A + B′ + 1 via XORs on B. Flags Z, N, C, V. Carry lookahead: G = AB, P = A⊕B, Cᵢ₊₁ = Gᵢ + PᵢCᵢ.

MUX

Select bits choose a data input. 2ⁿ:1 MUX has n selects. Can implement any truth table.

Decoders

n inputs → 2ⁿ one-hot outputs (each a minterm). Encoders go the other way. Equality = AND of XNORs.
