Computer Engineering · Unit 5

Circuits that remember

Latches, flip-flops, clocks, registers, counters and finite state machines: how circuits store information and step through time.

5.1Memory from feedback: latches

Combinational circuits forget everything the moment their inputs change. To build memory, you feed a circuit's output back into its own input. The simplest memory cell is the SR latch: two NOR gates, each feeding the other.

S (set)R (reset)Q nextMeaning
00Qhold: remember the last value
101set
010reset
11invalidboth outputs forced to 0; avoid

Once you set it, you can let go of S and the loop keeps Q = 1 forever (as long as there's power). That single loop is the origin of every bit of SRAM and every register in your computer.

Latch vs flip-flopA latch is level-sensitive: while its enable is 1, the output follows the input. A flip-flop is edge-triggered: it only looks at its input at the instant the clock rises (0 → 1), then holds that value for the whole cycle. Almost all processor state lives in flip-flops.

5.2Flip-flops and the clock

A clock is a signal that switches 0, 1, 0, 1 at a steady rate. Every flip-flop in a synchronous circuit updates at the same instant, the rising edge, so the whole system marches in lockstep. A 3 GHz clock has a period of 1/(3 × 10⁹) ≈ 0.33 ns.

Flip-flopInputsBehaviour at the clock edgeTypical use
D (data)DQ ← Dregisters: just store a value
T (toggle)TT = 1: Q ← Q′. T = 0: holdcounters
JKJ, K00 hold, 01 reset, 10 set, 11 togglegeneral purpose (fixes SR's invalid case)
SR (clocked)S, R00 hold, 01 reset, 10 set, 11 not allowedmostly historical

Timing rules

The input of a flip-flop must be stable for a short setup time before the edge and a hold time after it. Between two flip-flops, the signal has to get through the combinational logic in time:

Tclock ≥ tclk→Q + tlogic + tsetup
Worked example: A flip-flop has clock-to-Q delay 40 ps and setup time 30 ps. The slowest logic path between flip-flops is 430 ps. Maximum clock frequency?
T ≥ 40 + 430 + 30 = 500 ps, so f ≤ 1/(500 × 10⁻¹² s) = 2 GHz. To go faster you must shorten the critical path, for example by pipelining (unit 6).

5.3Registers and counters

Register

n D flip-flops sharing one clock store an n-bit word. A 64-bit CPU register is 64 flip-flops. Add a MUX in front of each D input to choose between loading a new value and keeping the old one (a load-enable).

Shift register

Flip-flops in a chain, each D fed by its neighbour's Q. Every clock edge shifts the bits one place. Used to turn serial data (one bit at a time, like USB) into parallel words, and back.

Binary counter

Each bit toggles when every lower bit is 1. With T flip-flops: T₀ = 1, T₁ = Q₀, T₂ = Q₀Q₁, … An n-bit counter counts 0 to 2ⁿ − 1 and wraps.

Register file

A small array of registers (say 32 × 64 bits) with a decoder to choose which one to write and MUXes to choose which ones to read. It's the fastest storage in the CPU.
Worked example: A 4-bit counter driven by a 1 kHz clock starts at 0. What does it read after 37 ms?
37 ticks. A 4-bit counter wraps every 16, so 37 mod 16 = 5 → 0101.

5.4Finite state machines

A finite state machine (FSM) is a circuit that remembers which of a fixed set of states it's in and moves between them based on its inputs. Traffic lights, vending machines, elevator controllers, network protocols and the control unit of a CPU are all FSMs.

  1. List the states (what does the machine need to remember?).
  2. Draw the state diagram: a circle per state, an arrow per transition labelled with the input that causes it.
  3. Write the state table: current state + input → next state (+ output).
  4. Give each state a binary code. k state bits can encode up to 2ᵏ states.
  5. Derive the next-state and output logic (K-maps!) and store the state in flip-flops.

Moore machine: outputs depend only on the state

S0 = haven't seen anything useful, S1 = just saw a 1, S2 = just saw 1 0, S3 = just saw 1 0 1 (output 1). From S3, a 0 means we've seen …1 0, which is S2, so the overlapping pattern isn't missed.

Mealy machine: outputs depend on the state and the input

Moore or Mealy?Mealy machines often need fewer states and react in the same cycle as the input. Moore machines are safer: their outputs only change on clock edges, so glitches on the inputs can't leak through.
Detailed explanationFrom state table to circuit: the 101 detector

Encode S0 = 00, S1 = 01, S2 = 10, S3 = 11 in flip-flops Q₁Q₀, with input X. Next-state table: S0: X = 0 → 00, X = 1 → 01. S1: 0 → 10, 1 → 01. S2: 0 → 00, 1 → 11. S3: 0 → 10, 1 → 01. Read off D₀ (next Q₀) = X. D₁ (next Q₁) is 1 for (S1, 0), (S2, 1), (S3, 0): D₁ = Q₁′Q₀X′ + Q₁Q₀′X + Q₁Q₀X′ = Q₀X′ + Q₁Q₀′X. Output Z = Q₁Q₀. Two D flip-flops and a few gates.

Unit summary

Latches

Feedback = memory. SR latch: set, reset, hold; S = R = 1 invalid. Latch = level-sensitive, flip-flop = edge-triggered.

Flip-flops

D: Q ← D. T: toggle when 1. JK: hold / reset / set / toggle. Clock period ≥ clk→Q + logic + setup.

Registers

n flip-flops = n-bit register. Shift registers move bits. Counters: bit k toggles when all lower bits are 1.

FSMs

States + transitions. Moore: output from state. Mealy: output from state + input. k flip-flops hold up to 2ᵏ states.
